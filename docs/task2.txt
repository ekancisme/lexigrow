PHÂN CHIA NHIỆM VỤ THỰC HIỆN TRANG QUẢN TRỊ VIÊN (ADMIN MANAGEMENT PORTAL) - 5 NGƯỜI

Hệ thống quản lý Admin sẽ được triển khai toàn diện và chia đều cho 5 người. Mỗi người sẽ chịu trách nhiệm trọn gói (Database, Backend API, và Frontend UI/UX) cho nhóm tính năng của mình để đảm bảo tiến độ độc lập, không chồng chéo:

================================================================================
NGƯỜI 1: QUẢN LÝ NGƯỜI DÙNG & PHÊ DUYỆT TÀI KHOẢN (USER MANAGEMENT & APPROVALS)
(Đảm nhận toàn bộ luồng quản lý người dùng, phân quyền và duyệt đăng ký của giáo viên/phụ huynh)
- [ ] Backend & Database:
  - Thiết kế API CRUD User (Xem danh sách, Tạo mới, Cập nhật thông tin, Xóa/Khóa tài khoản).
  - Thêm trường dữ liệu quản lý trạng thái tài khoản (Active, Suspended, Pending Approval) vào model [User.js](file:///c:/Users/binhv/Desktop/lexigrow/server/src/models/User.js).
  - Viết API phê duyệt/từ chối tài khoản Giáo viên (Teacher) và Phụ huynh (Parent) sau khi đăng ký.
- [ ] Frontend UI/UX:
  - Thiết kế trang Quản lý Người dùng (AdminUserManagement.jsx) hiển thị danh sách người dùng, hỗ trợ tìm kiếm, lọc theo vai trò (Role) và trạng thái.
  - Modal xem chi tiết người dùng, khóa/mở khóa tài khoản, đổi vai trò hoặc đặt lại mật khẩu.
  - Tab phê duyệt tài khoản chờ duyệt (Registration Requests) hiển thị thông tin đăng ký của giáo viên (tên, email, trường) kèm nút Duyệt/Từ chối.

================================================================================
NGƯỜI 2: QUẢN LÝ LỚP HỌC & ĐIỀU PHỐI HỌC SINH TOÀN HỆ THỐNG (GLOBAL CLASS MANAGEMENT)
(Đảm nhận quyền kiểm soát tất cả các lớp học của các giáo viên khác nhau và điều chuyển học sinh)
- [ ] Backend & Database:
  - Viết API xem danh sách tất cả các lớp học đang hoạt động trên hệ thống kèm thông tin giáo viên phụ trách và sĩ số.
  - Viết API buộc gia nhập, hủy gia nhập (Force Enroll/Unenroll) học sinh vào một lớp bất kỳ.
  - Viết API chuyển học sinh từ lớp này sang lớp khác (Transfer Student API).
  - Viết API đóng/lưu trữ lớp học (Archive Class) hoặc xóa lớp học nếu vi phạm.
- [ ] Frontend UI/UX:
  - Thiết kế trang Quản lý Lớp học Hệ thống (AdminClassManagement.jsx) danh sách tất cả lớp học kèm bộ lọc theo giáo viên.
  - Giao diện chi tiết lớp học từ góc nhìn Admin, cho phép xem danh sách học sinh của lớp.
  - Tính năng điều chuyển học sinh: Form chọn học sinh và chọn lớp đích để thực hiện chuyển lớp nhanh chóng.

================================================================================
NGƯỜI 3: CẤU HÌNH HỆ THỐNG & GIÁM SÁT MÔ HÌNH AI (SYSTEM SETTINGS & AI MONITORING)
(Đảm nhận cấu hình API Keys, điều chỉnh AI Prompts chung và theo dõi chi phí/lỗi AI)
- [ ] Backend & Database:
  - Thiết kế model Config (lưu các thiết lập động dưới dạng Key-Value).
  - Viết các API cấu hình hệ thống: Cập nhật API Keys (Groq, OpenAI, Llama), đổi mô hình AI mặc định, điều chỉnh các Prompt hệ thống dùng cho chấm điểm/phân tích bài viết.
  - Thiết kế DB lưu vết lượt gọi API AI (Model, Tokens sử dụng, thời gian xử lý, trạng thái thành công/thất bại).
- [ ] Frontend UI/UX:
  - Thiết kế trang Cấu hình Hệ thống (AdminSettings.jsx): Form nhập API Keys, dropdown chọn model, text area cập nhật các Prompt hệ thống của AI.
  - Thiết kế Dashboard Giám sát AI (AIMonitoring.jsx): Vẽ biểu đồ thống kê số lượt gọi AI, lượng token tiêu thụ (ước tính chi phí) và tỷ lệ lỗi API theo thời gian.

================================================================================
NGƯỜI 4: QUẢN LÝ THƯ VIỆN TỪ VỰNG HỌC THUẬT TOÀN CẦU (GLOBAL VOCABULARY & CURRICULUM)
(Đảm nhận việc quản trị kho từ vựng chuẩn, bộ từ khóa CEFR, AWL và import/export dữ liệu)
- [ ] Backend & Database:
  - Thiết kế model GlobalVocabulary để lưu trữ kho từ vựng chuẩn hệ thống (Từ, IPA, Loại từ, Nghĩa, Độ khó CEFR, phân loại AWL).
  - Viết API CRUD danh mục từ vựng chuẩn của hệ thống.
  - Viết API Import/Export bộ từ vựng từ file Excel/CSV để quản lý danh mục lớn nhanh chóng.
- [ ] Frontend UI/UX:
  - Thiết kế trang Từ điển Hệ thống (AdminVocabulary.jsx) hiển thị danh mục từ vựng, hỗ trợ tìm kiếm nâng cao và lọc theo cấp độ CEFR (A1-C2) hoặc AWL.
  - Modal chỉnh sửa thông tin từ vựng hệ thống.
  - Widget tải lên file Excel/CSV (Upload Wizard) hiển thị trạng thái import, đếm số từ được thêm mới/cập nhật và báo lỗi nếu định dạng sai.

================================================================================
NGƯỜI 5: BÁO CÁO THỐNG KÊ HỆ THỐNG & NHẬT KÝ HOẠT ĐỘNG (SYSTEM ANALYTICS & AUDIT LOGS)
(Đảm nhận tổng hợp số liệu hoạt động toàn hệ thống và ghi nhận nhật ký của admin/giáo viên)
- [ ] Backend & Database:
  - Thiết kế model AuditLog để ghi lại lịch sử thao tác quan trọng (Ai thực hiện, hành động gì, trên đối tượng nào, thời gian nào - ví dụ: Xóa lớp học, Đổi prompt hệ thống, Thay đổi quyền user).
  - Viết API thống kê hiệu suất hoạt động chung: đếm tổng số bài viết đã chấm, số học sinh tích cực, số giáo viên hoạt động theo tuần/tháng.
  - Viết API truy xuất danh sách Audit Logs kèm bộ lọc theo Admin/Giáo viên hoặc Loại hành động.
- [ ] Frontend UI/UX:
  - Thiết kế trang Báo cáo Tổng quan Admin (AdminAnalytics.jsx) hiển thị biểu đồ tăng trưởng người dùng, số lượng bài luận được nộp theo thời gian, tỷ lệ phân bố điểm số AI trên hệ thống.
  - Trang Nhật ký Hoạt động (AdminAuditLogs.jsx) hiển thị danh sách log chi tiết dưới dạng bảng, hỗ trợ tìm kiếm và lọc dữ liệu để phục vụ công tác giám sát hệ thống.
