II. Software Requirement Specification
================================================================================

1. Product Overview
--------------------------------------------------------------------------------
LexiGrow là hệ thống hỗ trợ học tập ngôn ngữ (Tiếng Anh) tích hợp công nghệ AI (NLP, LLM). Hệ thống giúp học sinh rèn luyện kỹ năng viết luận (Essay Writing), tự động phân tích và đánh giá các chỉ số từ vựng (TTR, lexical diversity MTLD/HD-D), cấu trúc ngữ pháp (câu bị động, mệnh đề phụ), phát hiện đạo văn chéo và cảnh báo sớm tình hình học tập. Đồng thời, giáo viên, phụ huynh và admin có các dashboard chuyên biệt để theo dõi tiến độ và quản trị hệ thống.

2. User Requirements
--------------------------------------------------------------------------------

2.1 Actors
*   **Học sinh (Student)**: Tác nhân trung tâm, viết bài luận, ôn tập từ vựng, chơi game học tập, tự đặt mục tiêu tuần.
*   **Giáo viên (Teacher)**: Quản lý lớp học, giao bài tập (assignment), nhận xét bài viết thủ công, theo dõi biểu đồ tiến độ học sinh.
*   **Phụ huynh (Parent)**: Liên kết với tài khoản của con để theo dõi tiến trình từ vựng, điểm số và nhận các cảnh báo sớm.
*   **Quản trị viên (Admin)**: Quản lý người dùng, lớp học toàn hệ thống, cấu hình tham số, giám sát token/logs AI và kho từ vựng toàn cục.
*   **Hệ thống & AI Agent (System)**: Tác vụ chạy ngầm (cronjob), phân tích NLP, đo độ đa dạng từ vựng, phát hiện đạo văn, AI writing và gửi cảnh báo sớm.

3. Functional Requirements
--------------------------------------------------------------------------------

3.1 System Functional Overview

3.1.1 Screens Flow
*   **Học sinh**: Login -> Student Dashboard -> Viết luận / Ôn tập / Vào Game Zone -> Xem phản hồi AI / Lịch sử bài viết.
*   **Giáo viên**: Login -> Teacher Dashboard -> Xem Lớp học -> Tạo Assignment / Chấm điểm thủ công / Xem học sinh yếu.
*   **Phụ huynh**: Login -> Parent Dashboard -> Nhập Student ID để link -> Xem chi tiết tiến độ con.
*   **Admin**: Login -> Admin Dashboard -> Quản lý User / Quản lý Lớp / Giám sát AI / Cấu hình API Keys.

3.1.2 Screen Descriptions
*   **Student Dashboard**: Hiển thị tổng số bài luận đã nộp, tổng từ đã học, tiến độ hoàn thành mục tiêu tuần, widget gợi ý từ vựng mới.
*   **Write Essay Screen**: Trình soạn thảo văn bản, hỗ trợ chọn prompt, lưu nháp tự động mỗi 30s, bôi đen để dịch qua AI Translator.
*   **Game Hub**: Màn hình trung tâm điều hướng sang 4 game: Matching (Thẻ 3D), Scramble (Sắp xếp từ), Filler (Điền từ ngữ cảnh) và Hunter (Bắn bong bóng).
*   **Teacher Class Overview**: Cho phép giáo viên theo dõi tiến độ viết bài và thống kê từ vựng của cả lớp.
*   **Parent Child Progress**: Cho phép xem lại điểm số, mục tiêu, biểu đồ từ vựng của con dưới giao diện trực quan.
*   **Admin AI Monitoring**: Thống kê số requests, token sử dụng, chi phí ước tính, tỷ lệ lỗi và latency trung bình theo thời gian thực.

3.1.4 Non-Screen Functions
*   **Cronjob Quét Cảnh Báo Sớm**: Chạy ngầm định kỳ hàng tuần quét điểm trung bình và số lượng từ vựng của học sinh để phát hiện stagnation (chững lại) hoặc regression (tụt dốc), tạo cảnh báo tự động gửi qua socket và email.
*   ** spaCy Parser Engine**: Thực thi qua command python phân tích cú pháp bài luận song song cùng lúc với API chấm bài chính.

3.1.5 Entity Relationship Diagram (ERD)
*   `User`: Lưu thông tin tài khoản, phân quyền (role: 'student', 'teacher', 'parent', 'admin'), trạng thái lock/unlock.
*   `Class`: Lớp học, quản lý bởi Teacher, chứa danh sách Học sinh.
*   `Assignment`: Bài tập do Giáo viên giao cho Lớp học, có deadline và tiêu đề.
*   `Essay`: Bài luận học sinh nộp, liên kết với `User` và có thể liên kết với `Assignment`.
*   `AIAnalysis`: Lưu kết quả chấm điểm của AI (Overall Score, grammar, coherence, nlpStats, plagiarism và aiDetector score).
*   `Vocabulary`: Danh sách từ vựng cá nhân của học sinh (Word, status: 'new'/'learning'/'mastered', ipa, definition, ví dụ).
*   `SystemSetting`: Cấu hình hệ thống (API keys, ngưỡng cảnh báo sớm).
*   `Notification` & `Comment`: Hỗ trợ luồng thông báo chuông và chat realtime dưới bài luận.

3.2 User Account Management

3.2.1 Login
Cho phép người dùng nhập Email và Password, hệ thống kiểm tra phân quyền, trạng thái hoạt động tài khoản và cấp token JWT lưu trữ ở Client để xác thực các API.

3.2.2 Logout
Xóa token JWT phía client, hủy kết nối socket và đưa người dùng về trang Đăng nhập.

3.2.3 Forgot Password
Gửi email chứa link hoặc mã đặt lại mật khẩu tạm thời cho người dùng.

3.2.4 Change Password
Học sinh, giáo viên, phụ huynh và admin có thể đổi mật khẩu mới trong màn hình Profile Settings bằng cách xác nhận mật khẩu cũ.

4. Non-Functional Requirements
--------------------------------------------------------------------------------

4.1 External Interfaces

4.1.1 Database Interfaces
Hệ thống sử dụng cơ sở dữ liệu NoSQL **MongoDB** (thông qua thư viện Mongoose), kết nối bảo mật qua URI, tối ưu hóa các index cho tìm kiếm từ vựng và lịch sử bài luận.

4.1.2 API Interfaces
Xây dựng theo chuẩn **RESTful API**, dữ liệu truyền nhận dạng JSON, có tích hợp các Middleware xác thực JWT, phân quyền Actor và kiểm soát số lượng request (rate limit).

4.1.3 Frontend Interfaces
Xây dựng SPA bằng thư viện **ReactJS + Vite**, sử dụng Material Symbols cho hệ thống icon, tối ưu giao diện Responsive (Mobile/Tablet/Desktop).

4.1.4 External Service Interfaces
*   **Groq API**: Dùng mô hình Llama-3.3-70b-versatile để chấm bài luận và enrich từ vựng.
*   **Hugging Face Inference API**: Chạy mô hình RoBERTa phát hiện AI writing.
*   **Nodemailer / SMTP Service**: Gửi mã OTP xác thực và gửi email thông báo cảnh báo sớm.

4.2 Quality Attributes

4.2.1 Usability
Giao diện thân thiện với học sinh, sử dụng hiệu ứng 3D Flashcards trực quan, hỗ trợ dịch thuật nhanh bằng thao tác bôi đen tiện lợi.

4.2.2 Reliability
Tự động lưu nháp bài viết của học sinh đề phòng mất mạng, hệ thống phân tích song song (AI, spaCy, Plagiarism) chạy bất đồng bộ để tránh crash luồng chính.

4.2.3 Performance
*   Thời gian phản hồi phân tích ngôn ngữ tự nhiên spaCy dưới 2 giây.
*   Hạ tầng realtime truyền nhận tin nhắn/thông báo dưới 500ms.

5. Requirement Appendix
================================================================================

5.1 Business Rules
*   **Ngưỡng Đạo Văn**: Bài viết có chỉ số tương đồng Jaccard 3-Gram >= 25% với bài viết khác sẽ bị gắn cờ cảnh báo đạo văn.
*   **Ngưỡng Phát Hiện AI**: Bài viết có xác suất sinh bởi AI >= 70% sẽ bị đánh dấu nghi vấn sử dụng AI.
*   **Mức Thành Thạo Từ Vựng**: Mặc định từ mới thêm vào ở trạng thái `New`, ôn tập Flashcard đúng tăng lên `Learning`, sau 3 lần ôn tập chính xác sẽ được cập nhật lên `Mastered`.

5.2 Common Requirements
Hệ thống tuân thủ các tiêu chuẩn bảo mật dữ liệu, mã hóa mật khẩu người dùng bằng bcrypt trước khi lưu vào cơ sở dữ liệu.
